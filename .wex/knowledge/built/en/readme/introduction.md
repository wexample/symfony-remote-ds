`symfony-remote-ds` is the screen of `symfony-remote`, built on the design system: a page listing every remote of the application with its state, latency and message, and a "Test" button per row. The page renders the list at once and each row checks itself afterwards, so one slow service delays its own row and nothing else. Page and endpoint are restricted to `ROLE_ADMIN`: every check reaches out to a service outside the application.
